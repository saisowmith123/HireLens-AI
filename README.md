# HireLens AI

HireLens AI is an AI-powered ATS resume analyzer that compares a resume with a job description and gives an ATS score, missing skills, and improvement suggestions.

## Features

- Upload resume and job description files
- Supports PDF and DOCX formats
- Calculates ATS score using skill match, experience relevance, and project relevance
- Highlights matched and missing skills
- Provides AI-based improvement suggestions

## Tech Stack

- Python
- Flask
- Gemini API
- HTML
- CSS
- JavaScript
- Bootstrap

## Scoring Logic

The ATS score is calculated using:

70% Skill Match  
20% Experience Relevance  
10% Project Relevance

## Run the Project

pip install -r requirements.txt

python app.py


## Conclusion

HireLens AI helps users understand how well their resume matches a job description and gives practical suggestions to improve it.
